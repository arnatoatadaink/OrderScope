## 4. External-request enforcement

A News scheduled unit must consume from the same per-invocation external-request budget as Market work.

Rules:

1. combined acceptance ceiling is 40, not Cloudflare's hard 50;
2. provider retry attempts count as News external subrequests;
3. do not request a next News page if the next request would exceed the remaining OrderScope budget;
4. first normal unit is AMD page 1 + NVDA page 1;
5. second pages are optional only while combined budget remains safe;
6. if more data exists after the second page, return partial/retryable and preserve resumable checkpoint state;
7. never report fully complete coverage after budget exhaustion.

## 5. D1-query enforcement

Measure all D1 operations generated by the same scheduled invocation.

Rules:

1. combined acceptance ceiling is 40 queries;
2. article persistence must not create an unbounded one-query-per-observation path up to 200 observations;
3. prefer bounded batched/indexed identity resolution and writes;
4. same provider article from AMD/NVDA must remain one durable article with both query memberships;
5. checkpoint/digest/error-path D1 work counts toward the same combined budget;
6. if a safe implementation cannot stay <=40 without weakening Market behavior, stop and report `Blocked`.

## 6. Required checkpoint outcomes

Prove all of these:

```text
full bounded page exhaustion -> completeThrough may advance
page cap reached with next token -> partial/retryable; no false complete advance
external budget exhausted -> partial/retryable; no false complete advance
D1 budget exhausted/prevented -> fail closed/partial; no false complete advance
429 -> retryable; Market path remains valid
500 -> retryable; Market path remains valid
invalid/looping page token -> fail closed; no false complete advance
missed 5-min tick -> next bounded overlap recovers
```

Historical catch-up is out of scope.
