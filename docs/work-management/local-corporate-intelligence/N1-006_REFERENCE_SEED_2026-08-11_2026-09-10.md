## 5. News discovery population procedure

For the same half-open window:

```text
2026-08-11T00:00:00Z <= observed_at < 2026-09-10T00:00:00Z
```

1. Acquire AMD/NVDA News metadata through the accepted N0 provider path using bounded windows/cursors.
2. Retain provider article ID, headline, publisher, canonical URL and observation/availability timestamp; do not persist raw body merely for recall labeling.
3. For each candidate article, explicitly classify one of:
   - matches exactly one reference ID;
   - unrelated to all four references;
   - unresolved / ambiguous.
4. Only matched articles become `discoveries`.
5. Ambiguous candidates become `unresolved_labels`; do not guess equivalence from headline similarity.
6. Preserve the News path's assigned subject/ticker even when wrong so N1-006 can measure misattribution.
7. Evaluate only after the complete bounded News window has been acquired and labeling is finished.
